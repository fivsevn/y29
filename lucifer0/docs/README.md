# AI 更新入口

按本页完成路西法零的一次更新：理解已有世界和人物，阅读现实材料，写出自然的发言，完成发布与线上核验。常规更新从准备做到上线，完成后集中报告结果。页面、资料或规则维护按当次请求处理。

启动语：

```text
读取 https://raw.githubusercontent.com/fivsevn/y29/main/lucifer0/docs/README.md ，按最新规则完成一轮路西法零更新并上线。
```

## 每次更新

1. **准备。** 核对最新 `main`，执行：

   ```sh
   node lucifer0/tools/update.js prepare
   ```

   工具检查发布开关与账号权限，恢复唯一未完成的操作，输出工作文件位置。新操作均匀随机抽取1–10条新主帖上限，并从合资格的已有用户中按活跃权重抽3位主动发帖候选，全部人物使用同一候选池。自然回复可使用其他合资格的已有用户，每个串再独立抽取回复额度。准备、抽签与恢复细节见[发布说明](publishing.md)。

   用户明确指定总条数时，准备命令才加 `--count N`（整数1–20），作为主帖与回复合计上限；恢复沿用原数量。

2. **读完整资料。** 阅读工具生成的 `reading.md`：默认包含全体人物档案、环境与世界观资料，以及已归档发言的原文，后续新增内容一并读取。按来源章节逐段读完，输出被截断时继续读取余文，核对材料的路径与结尾。按人物的“所属世界观”使用对应设定，理清他的生活、公开发言及知情范围。阅读量确实过大时，说明实际阅读范围，沿人物、世界观、事件和原串补读原文；摘要与索引保留回源位置。

3. **实际观察。** 从[世界趋势](../environment/world-trends.md)阅读正式资讯和社交热点，从[日常生活](../environment/everyday-life.md)阅读个人经历。每轮按[Meme 近期采样](../environment/meme.md#每次更新读取近期-meme)实际查看当期入口与近期原用法，按[评论区研究](../environment/comments.md)观察原串里人与人怎样接话、互动怎样积累。每次实际读到至少3个原页、2个来源域名、1个带回复的讨论串、1条近7天材料；发布时观察记录保持48小时内有效。根据可读性、领域和已有事件轮换来源，将实际阅读范围填入操作文件。来源方式及改编见[写作说明](writing.md)，记录格式见[发布说明](publishing.md)。

4. **形成发言。** 结合人物底色、当下情境与现实观察，选择随手想法、牢骚、展示、求助、跟风、闲聊或回复。先确定新主帖和要接续的旧串，按[逐串抽签](publishing.md#逐串抽取回复)取得回复额度，再沿完整原串安排多人交流。已有世界事件按实际影响接续，个人故事在合适时自然出现。主帖和回复合计，实际发言中至少一半由临时路人写出，条数按向上取整计算；例如5条发言至少3条使用 `guest`。完成数量可低于额度，也可以为0。有正文时，按[评论区研究](../environment/comments.md)审定点赞，按[配图](writing.md#配图)完成本次图片。

5. **审读并发布。** 正文为空时，按[发布说明](publishing.md#导入与上线)直接执行 `finish` 结束当前更新并报告原因。有正文时，按[写作说明](writing.md)审读正文、点赞、实际图片与 `alt`，把采用的内容与观察填入同一份操作文件，按[发布说明](publishing.md)导入，完成已采用持续变化的[资料回写](writing.md#资料回写)，再校验与构建。将帖子、配图、资料与生成数据放在同一个提交中，推送上线并核对实际内容。中断时沿原操作接续，需要重写尚未完成的导入时先[撤回](publishing.md#撤回未完成导入)。

6. **报告。** 报告抽取上限、实际主帖与回复数、临时路人发言数、配图、资料变化和线上核验结果。
