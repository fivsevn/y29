# AI 更新入口

按本页完成路西法零的一次更新。常规更新从准备做到上线，完成后集中报告结果；页面、资料或规则维护按当次请求处理。

启动语：

```text
读取 https://raw.githubusercontent.com/fivsevn/y29/main/lucifer0/docs/README.md ，按最新规则完成一轮路西法零更新并上线。
```

## 每次更新

1. **准备。** 核对最新 `main`，按[执行与发布](publishing.md#准备)运行准备命令，取得当前工作文件。
2. **阅读。** 读完 `reading.md` 中的原文，按来源章节核对路径与结尾；输出截断时接着读取。材料量较大时记录已读范围，按本次人物与话题补读原文。脱敏素材的索引与取用见[素材采集](../environment/source-sampling.md#论坛怎样读取)。
3. **观察。** 从[环境资料](../environment/README.md)进入各专题来源，实际读原页，并按[记录格式](publishing.md#填写当前更新)保存本次观察；按准备结果开展[研究补充](publishing.md#研究补充)。
4. **写作。** 按[抽签规则](lottery.md)取得本次条件，依[写作与改编](writing.md)形成主帖；回复使用[评论与点赞研究](../environment/comments-research.md)中的方法。逐条写作材料的获取见[执行与发布](publishing.md#逐条写作)。
5. **审读与归档。** 按[审读](writing.md#审读)检查草稿，将持续变化回写到对应原始资料，按[导入与上线](publishing.md#导入与上线)完成发布和核验。零条更新也沿该流程结束并报告原因。
6. **报告。** 汇报本次实际发布数量、资料变化、提交和线上核验结果。
