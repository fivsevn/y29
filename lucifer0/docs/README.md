## 职责与适用范围

路西法零以许多陌生人的独立发言与局部来往形成“虚构的真实”。人物档案约束本人事实与知情范围，研究提供观察方法和样本，抽签提供表达机会；它们共同服务实际交流，不把每条发言变成展示人物、推进故事或完成检查项的任务。

| 依据 | 负责决定的内容 |
| --- | --- |
| 用户本次请求 | 本次工作的范围；常规更新、规则维护和明确指定的历史修订分别处理。 |
| `publication.json` 与[抽签规则](lottery.md) | 新操作的参数、额度、机会与保存语义。已有操作沿原抽签快照，不因规则更新重抽；当前权限、真实时间和资料事实仍须核对。 |
| [写作与改编](writing.md) | 原创与案例怎样形成发言、知情边界、媒体用途及整轮审读。 |
| [本站化](localization.md) | 公开发言中的站内表情、颜文字与称呼，以及外部表达的转换边界。 |
| [执行与发布](publishing.md) | 实际命令、工作字段、导入、上线核验与清理。 |
| 人物、世界观与专题研究 | 已有事实、表达习惯、观察方法及其证据。研究样本的比例不直接变成本站参数，也不另设每轮必做任务。 |

数值只在配置中调整，规则语义在抽签页说明，创作判断在写作页说明，本站表达转换在本站化页说明，执行步骤在发布页说明。同一要求在其他入口以链接取用；发现不一致时先核对当前操作版本与各文档职责，再修订原处，避免增加一条相互覆盖的新规则。

## 开始工作

常规更新从[准备](publishing.md#准备)开始，完成原创与本轮固定案例后一起发布。阅读包提供完整规则、人物、世界观、研究及近期对照；历史帖子保留在原发布包，具体作者与目标串的材料由 `brief` 按需取得，不要求每轮重新通读全部历史。单条写作者只接收本条 `writer`，整轮资料由策划者审读。

资料或规则维护直接按本次请求修改、检查并提交，不为维护启动新的发帖操作。已启动的日常更新中途受限时保留原操作继续；完成与恢复边界见[保存与恢复](lottery.md#保存与恢复)。
