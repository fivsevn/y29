## 使用说明

常规更新按本目录的执行与发布流程完成一次路西法零帖子更新并上线，创作与抽取条件分别按写作与改编、抽签规则处理；资料或规则维护按当次请求处理。

### 给 AI 的启动语

```text
读取 https://raw.githubusercontent.com/fivsevn/y29/main/lucifer0/docs/README.md 及其链接的发帖与发布说明，按最新 main 完成一次路西法零帖子更新并上线。
```
