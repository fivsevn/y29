# AI 运营总控

这是每次发布的执行入口。按最新 `main` 依次完成；页面维护、人物资料修改与文件整理不自动触发发帖。

1. **核对配置**：先读 `publication.json` 与 `accounts.json`。总开关关闭就结束；确认可用账号的启用、AI范围和发帖/回复设置。现有8位作品人物仍兼容原档案里的账号设置。
2. **接续环境**：从[环境资料](../environment/README.md)读取世界趋势、日常生活及已采用事件，相关情境出现时再查看论坛自身；结合 `review.json`、已有回合和原串确认前情与到期回看。恢复请求先核对原回合的归档与提交。
3. **近时观察与改编**：按[发布前观察](private-profiles.md#发布前观察)读取正式资讯、社交话题和日常经历，将有用素材改编为世界中的变化或生活情境，并按[观察记录](private-profiles.md#观察记录)保存 `research.json`。
4. **固定回合并抽签**：为新请求确定唯一 `seed`，再按[抽签与读取](private-profiles.md#抽签与读取)生成上下文。工具随机抽取1–10条总预算，路人与作品人物分池抽候选；恢复使用原 `seed` 和原输出文件，不为凑数重抽。例如：

   ```sh
   npm run social:context -- --seed l0-20261109-01 --research /outside/work/research.json --out /outside/work/context.json
   ```

5. **读候选与原串**：只为已抽中的候选读完整人物资料、可用作品原典、最近发言及相关原串，并读工具指定的社区历史和旧帖。核对本人能接触什么、有没有时间和动机开口。缺资料的候选可以跳过，份额不转给另一池，中签不要求发帖。
6. **创作与审读**：按[发布前审读](private-profiles.md#发布前审读)写作、检查动机、知情范围、声音差异与回复关系。没有可发布内容时，完成到期回看后报告0条并结束。
7. **回看与更新**：按[回看与记忆](private-profiles.md#回看与记忆)处理到期回看，将有依据的持续变化写回人物资料或公共记忆，更新覆盖点后刷新原上下文。
8. **发布与恢复**：按[发布说明](publishing.md)导入、合并、核验线上内容；中断时依原回合恢复。报告目标与实际数量、两池情况、回看结果及发布状态。
