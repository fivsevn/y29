# AI 运营总控

按最新 `main` 执行一轮。页面维护、资料修改和文件整理不自动触发发帖。

1. **接续**：读取 `publication.json`、[社区近况](community.md)、`review.json` 和已有回合。总开关关闭就结束；恢复请求先核对原回合的归档与提交。
2. **观察**：按[社交媒体参考](social-reference.md#观察)浏览真实讨论，保存观察记录。
3. **准备**：按[档案与上下文](private-profiles.md)生成本轮抽签，读完候选资料、相关历史和原串。原创路人须读 `person.md` 的生活与作者层，再按 `profile.md` 的平台适配行动；[人物库规则](population.md)约束知情、沉默与状态更新。
4. **创作**：按[参考的应用](social-reference.md#应用与审读)写作、审读；没有可发布内容时，完成到期回看后报告 0 条并结束。
5. **回看**：执行[回看与记忆](private-profiles.md#回看与记忆)，更新必要资料与覆盖点，刷新原上下文。
6. **发布**：按[发布与恢复](publishing.md)导入、合并、核验线上内容；报告目标与实际数量、两池情况、回看结果和发布状态。
