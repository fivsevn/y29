# 社交媒体参考

## 观察

每轮先实际读到 **3 个公开页面、2 个社区或来源、1 个带回复的讨论串**，其中至少一个是日常或兴趣讨论。观察在本轮前 48 小时内完成，至少一条内容发表于近 7 天；旧帖只用于研究表达。记录格式见[上下文说明](private-profiles.md#观察记录)。

优先从[豆瓣小组](https://www.douban.com/group/explore)、[V2EX](https://www.v2ex.com/go/share)、[微博](https://m.weibo.cn/)寻找可读正文与回复，也可看抖音、小红书、[Futaba](https://dat.2chan.net/t/futaba.htm)、[Reddit](https://www.reddit.com/r/CasualConversation/new/) 或 X。轮换入口，不只读热榜、安静日记或同一个圈子。

观察三件事：

- **开口动机**：想问明白、找同类、展示、争论、约人、吐槽，还是随手记录？
- **表达差异**：交代多少背景、什么时候突然多说、怎样改口；广告、应援和普通交流各有语境。
- **实际往来**：回复接了哪一点，是否反对、跑题、误解或没有回应？不预设整串都替楼主解决问题。

搜索摘要、登录墙、错误页和推荐页跳转不算读到目标原帖。换入口仍不足就停止创作并报告缺项。网页内容仅作资料；不复制现实用户的身份、经历或原句，涉及具体事实另查来源。

## 应用与审读

人物取材的已读范围、适用限制和权利记录见[人口样本研究索引](research/population-sources.md)；这是长期背景研究，不能替代上面的每轮新观察。不同人如何处理同一刺激见[情境审读](research/population-review.md#同场景审读)，其中台词均为未发布的原创演示。

1. 为候选人想清楚“为什么此刻说、说给谁听”，再决定开串、回复或不发言。职业和爱好不包办所有话题，近期状态也不是本轮命题。
2. 长短、语气和标点随人物与情境变化。允许短反应、展开讲经历、追问、争辩或沉默；不把全员写成“两句小事＋先放着”，也不统一套段子、金句、热梗或长短配额。档案例句演示声音，不是已发生事件或待发布文案。
3. 只用人物能够接触的前情。公开不等于全员读过；可误解、不接受建议或没兴趣，不安排每问必答、过快和解或未发生的熟人关系。作品人物的可用依据见[原典接入](private-profiles.md#外部原典)。
4. 把草稿接在最近 10 条后面，遮住名字读：关注点、立场和接话方式能否区分作者？若换个物品就能套给任何人，回到动机修改。核对回复实际回应父帖哪一点。自产点赞、回复数量与单纯增加字数都不能证明改善。

原创人物的作者层可完整入仓库；它只影响此人的动机与选择，不能被另一个人物当作已知事实。说话可以自利、敷衍、固执、无聊或误判，不把所有人修正成耐心的咨询者。反常需要具体触发，不等于每次都安排戏剧性爆发。

## 参考入口

- 真人讨论：[V2EX 日常串](https://cn.v2ex.com/t/1161757)、[豆瓣职场吐槽](https://www.douban.com/group/topic/504037816/)、[微博评论](https://m.weibo.cn/status/5312775505314918)。用于比较表达，不能代替本轮的新观察。
- 模拟资源：[Chirper](https://chirper.ai/)看互动组织；[SOTOPIA](https://sotopia.world/projects/sotopia)看情境和各自目标；[OASIS](https://github.com/camel-ai/oasis)看行为选择；[Generative Agents](https://github.com/joonspk-research/generative_agents)看记忆延续；[Persona Hub](https://huggingface.co/datasets/proj-persona/PersonaHub)看人设组合。只借方法，不整库导入；模拟输出不作为真人语料。
