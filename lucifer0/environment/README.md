# 环境资料

世界设定、动态记录与各专题取材研究的入口。

| 文档 | 内容 |
| --- | --- |
| [世界观](worldviews/README.md) | 已登记世界的简介、设定与动态记录入口 |
| [世界观研究](worldview-research.md) | 世界设定的组织方法与框架参考 |
| [日常生活研究](everyday-life-research.md) | 人口、劳动、收支、职业任务与公共服务资料，以及日常生活场景 |
| [负面与争议研究](negative-research.md) | 八卦、抱怨、爆点与冲突讨论的实际样本和话头结构 |
| [Meme 研究](meme-research.md) | 表情包、反应图、网络句式的资源与用法 |
| [评论与点赞研究](comments-research.md) | 回复行为、互动样本与点赞差异 |
| [论坛自身](forum.md) | 平台自身事件与公共记忆 |

人物的经历、私人关系和持续变化保存在 [users](../users/README.md)。观察、发帖与改编方法见[发帖与改编](../docs/writing.md)，更新步骤见[AI 更新入口](../docs/README.md)；已发布内容保存在 [posts](../posts/)。

研究资料按当前的主要观察点归位：共同生活的条件与场景放在日常生活研究，个人经历、自述和人物刻画方法放在[人物研究](../users/character-research.md)，世界或地区怎样运行放在世界观研究与相应世界资料。同一来源可以支持多个方向，主体记录保留一处，其他位置链接取用；研究重点改变时也可以调整归属。现实资料被具体采用后，再把相应的虚构公共变化或个人经历写回所属世界、论坛或人物。
