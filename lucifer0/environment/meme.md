# Meme 研究

这里研究网络梗怎样被借用、改写、接住和用旧。文字句式、表情图、截图格式、声音节奏和动作都可以成为表达材料；使用者带着自己的处境再做一点变化，让看过相近内容的人认出其中的意思。

本篇给路西法零提供现实用法与改编依据。多人交往和点赞见[评论与点赞](comments.md)，公共事件与传播阶段见[世界趋势](world-trends.md)，图片制作见[配图](../docs/writing.md#配图)。

选材聚焦日常生活、游戏、手作、宠物和兴趣娱乐，排除中文政治与中国品牌相关内容。现实样本和虚构改编都按这一范围选择。

## 每次更新读取近期 Meme

每次更新都实际查看近期材料，沿下面的入口发现候选，再阅读它们最近的具体用法。静态样本提供观察方法，当次采样提供人物此刻可能接触的表达。

1. **看当期目录。** 至少打开一个按新收录、新上传或发帖时间排序的入口，确认当前排序、页面时间与实际读到的范围。优先查看最近7天，材料较少时扩展到30天；不同更新轮换中文、外文和兴趣圈来源。
2. **沿候选回源。** 先按本篇选材范围核对主题和出处，再选1–2个候选，阅读近期使用的原帖与可见接梗回复。词典给出的出处可沿链接核对；只列名称、原作日期或媒体题名时，继续寻找实际使用。出处或所涉对象尚未核清的候选留作待查，继续选其他材料。
3. **分清三个时间。** 分别看原素材或旧梗的时间、词条收录及修订时间、这次实际使用的时间。旧梗的新变体也能提供近期表达；榜单数字按该站、该排序和该时段记录。页面出现旧缓存或时间不一致时，保存实际所见并继续找其他可读原页。
4. **留下本次观察。** 在操作文件现有 `research` 中分别保存发现入口与原使用页面，标记 `purpose: "meme"`；`category` 沿用 `trend` 或符合内容的类别。`summary` 写明“发现入口”或“近期原用法”、实际读取范围、页面排序及时间、可借用结构和采用方向；日期未知时照实填 `null`，有相对时间就记入说明。这些页面可同时计入当次趋势或日常观察。
5. **按人物选择采用。** 完成观察后，结合当事人的兴趣、知情范围和眼前话题决定是否用梗。合适的新变体可以改写进正文；没有合适候选时，报告本次查看范围与结果，普通发言和已有表达照常形成。每次采样的记录保留，实际采用与观察结果分别交代。

## 看一个梗时看什么

可以从三个方向拆开看：这次在说什么、借了什么表达形式、说话者带着什么态度。这个观察角度参考 Limor Shifman 的[论文摘要](https://cris.huji.ac.il/en/publications/memes-in-a-digital-world-reconciling-with-a-conceptual-troublemak/)中的内容、形式和立场划分；本次已读作者所在大学的摘要与书目信息，论文发表于2013年。

同一句话可以是自嘲、夸奖、阴阳怪气，也可以是认真说完后被别人当成梗。对照主帖、引用对象和后面的接话，才能看出当事人这次在做什么。一个视频被原样转发，和许多人沿相同结构各写一个版本，提供的是两种传播经验；[MIT Press 的书籍简介](https://mitpress.mit.edu/9780262525435/memes-in-digital-culture/)可作为模仿与变体的研究入口，本次读取范围为简介。

观察时保留这些信息：

| 观察点 | 实际要读到的东西 |
| --- | --- |
| 前情 | 这句或这张图在回应什么，理解它需要知道哪些事 |
| 可重复的形式 | 哪段句式、图文关系、停顿或动作被保留下来 |
| 这次的变化 | 替换了什么人、物件、经历或结尾，意思怎样跟着变化 |
| 使用者与受众 | 哪个圈子里的人在用，谁认出来、谁询问、谁另作理解 |
| 接话效果 | 后面的人怎样复读、续写、解释、纠正或转走话题 |
| 时间与范围 | 原材料日期、本次访问时间、可确认的流行阶段和实际可见范围 |

梗名和出处帮助回源，具体用法从实际发言中理解。最早能核对的出处、本次读到的变体和当前热度分别记录；单个圈子里的可见使用就按这个圈子的范围保存。

## 实际读到的样本

以下样本访问于2026-11-09。旧材料用于观察当时的表达方式，采用时再读最近的实际使用。日期以原页可确认的信息记录，只有相对年数的页面记为 `null`。

### M01：做饭失败也能接成一段反转

[豆瓣：做饭失败后的吐槽与接话](https://www.douban.com/group/topic/504108531/?_spm_id=MTUxNjQ1MDMz)。原始发布时间：`null`；页面显示已编辑时间为 `2026-10-30 19:52:53`。已读标题、正文、第一页最赞回复和楼主引用的几条回复；附图和第二页未读。

有人先认真夸做饭的心意，括号里突然把试吃推给“楼下”；有人用“少了→正好→多了→完了”的递进结构讲面量失控，还有人给失败的菜换个名字找台阶。参与者借同一次失败各写一小段，反转、递进和重新命名成为可继续换细节的表达结构。

### M02：认出来本身也能成为笑点

[Reddit OutOfTheLoop：这些奇怪的 meme 是什么](https://www.reddit.com/r/OutOfTheLoop/comments/yefe3l/whats_the_deal_with_these_unusual_memes/)。原始日期：`null`。已读主帖及 Best 排序下返回的部分评论，包括 Loss 解释、The Game 接龙和解释后仍觉得无趣的分支；隐藏回复、图片与外链图片未打开。

评论者把模板解释为可以不断简化、藏入其他内容的结构，辨认过程又引出另一个梗的接龙。有读者听懂解释，仍然觉得没有那么好笑。这些差异可用于区分人物的识别、兴趣和参与意愿。

### M03：同一个圈子，也会争谁用得合适

[Reddit Bo Burnham 圈层：品牌参与玩梗的争论](https://www.reddit.com/r/boburnham/comments/nxyrr8/ughhh/)。原始日期：`null`。已读页面文字、前部评论、短句接龙，并定位阅读品牌争论与两处模板回应；图片、原推文与隐藏评论未打开。

有人认为品牌在蹭梗，有人认为被提到后自嘲也合理，双方都以自己对作品的理解判断这次使用。评论中出现让品牌闭嘴的短句，以及把固定称呼句式里的对象换成零食品牌的改写；也有人把陌生品牌误当成人名。即使在同一粉丝圈，文化知识和对说话者的看法也会改变接梗效果。

## 人为什么在这里用梗

有人借熟悉的句式讲自己的倒霉事，有人用一个表情代替长解释，有人认出同圈的人就顺手接下一句。起哄、找认同、缓解难堪、含蓄拒绝、挑衅和故意装正经，都可以成为这次开口的理由。表达的对象仍是眼前这件事。

同一模板可以被不同人说出不同的分量：有人原样回半句，有人把里面的物件换成自己的，有人只记得节奏，拼出一个不太准确的版本。对面可以接得很快，也可以问是什么意思、按字面回答、嫌已经用过太多次，或者继续聊原来的事。交流的后续沿这些反应形成。

人物接触什么内容，结合他的兴趣、生活圈、上网习惯和既有发言判断。相近年龄的人可以使用完全不同的表达；平时爱用旧梗的人偶尔说一句新词，少发言的人也可能刚好知道某个小圈子的说法。使用频率和熟练程度各自积累。

## 传播与用旧

沿原材料看一种说法怎样被模仿、替换和转到另一种处境。进入新圈子后，有人补解释，有人省略前情，也有人把原来的认真态度翻成反讽。语言、字幕和图文位置随使用情境调整，意思可能继续分叉。

热度有自己的时间：集中出现、被更广的人群套用、被说用腻、只在一部分人那里继续使用，都可以成为可观察的阶段。老梗也会因新事件重新被拿出来。当次采用前，结合最近的实际使用确认阶段，旧样本继续提供结构和语气的参考。

采用时沿上面的入口与[世界趋势的社交平台来源](world-trends.md#社交平台来源)继续查原帖和回复。声音和动作类表达可以通过人物的文字引用、讨论和反应进入当前帖子。

## 改编成路西法零的表达

先看当事人这次想说什么，再选择他可能拿来用的结构。普通反应和生活牢骚可以沿节奏、对照关系或替换位置重新写；涉及现实人物、机构和新闻前情时，结合世界里已经成立的虚构对应形成自己的版本。

图片梗的观察重点是表情、对照、构图与文字之间的关系。本站版本按[配图](../docs/writing.md#配图)制作，采用独立生成的画面和符合人物处境的文字。句式、图片和语气可以分别改写，最后连着正文与原串检查，确认这次的意思能被读出来。

一串里有人先抛出一个说法，别人重复其中一截，第三个人再换一个对象，局部的共享理解就可能积累。把已经发生的引用和参与者留下来，后面出现的人沿自己接触过的内容使用。人物对外来梗的理解、误解和兴趣也可以各自停在不同位置。

## 观察与延续

本次观察随更新记录保留原页、日期、实际读取范围、使用情境和采用方向。把梗放回完整发言审读：这是谁会说的话、回应了什么、改了哪里、旁人怎样理解。长短和出现密度随人物与话题安排。

实际采用后，公共传播与事件进展接回[世界趋势](world-trends.md)，站内反复引用形成的共同经历接回[论坛自身](forum.md)，稳定的个人表达习惯随本人档案积累。这里持续补充现实样本和观察结论，具体发言保存在原帖。
