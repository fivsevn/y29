# Meme 研究

这里保存表情包、反应图和网络句式的资源入口与选用方法。先理解说话者此刻的处境，再找他会顺手拿来用的表达。选材聚焦日常生活、游戏、手作、宠物和兴趣娱乐，排除中文政治与中国品牌相关内容。

通用写作见[写作与改编](../docs/writing.md)，数量与概率见[抽签规则](../docs/lottery.md)。本篇维护资源入口与用法观察，具体取图、处理与 WebP 归档见[执行与发布](../docs/publishing.md#生成并归档配图)。

## 从此刻的情绪选图

1. **先说清这张图要干什么。** 是懒得解释、假装镇定、表达困惑、晒一个失败现场，还是单纯觉得好笑？用这个动作搜“困、愣住、收到、算了、猫、游戏输了”等词，再结合当事人的兴趣缩小范围。
2. **找到现成表达，再决定怎样用。** 合适的旧表情、作者开放分享的图、自己的截图、简短字图和自行制作的画面都可以进入候选。选图时看表情、文字、动作和前情怎样一起传达意思；熟悉的旧图也可以反复使用。
3. **沿候选找到具体来源。** 从合集或搜索结果进入单图页，打开完整图片，确认字、裁切范围和动态内容；再沿作者、水印、文件说明或原作链接确认出处。找到作者的分享条件、原文件许可或对应授权后，按这些条件选用。搜索结果和聚合站提供发现线索，可使用依据落实到这一张素材。
4. **放回这条帖子判断。** 图片可以补充现场、替代一句反应，或独自成为一条发言。人物可以配图只写半句、继续用自己的老图；按[配图](../docs/writing.md#配图)审读实际画面。
5. **随采用记录出处。** 按[配图归档](../docs/publishing.md#生成并归档配图)保存来源和使用依据。来源还在核查的候选继续作为研究材料，可直接选用的候选进入发布流程。

## 图片可以有不同的完成程度

| 想表达的动作 | 可以采用的样子 | 选用时看什么 |
| --- | --- | --- |
| 代替一句话 | 反应图、旧表情、单个符号、短字图 | 表情是否就是当事人这一刻的态度，图中文字能否独立理解 |
| 给人看自己遇到什么 | 自己或获准使用的手机截图、现场随拍、屏幕局部 | 保留话头需要的细节，处理个人信息，核对截图里的时间和虚构世界语境 |
| 指出一个小问题 | 局部裁切、圈画、箭头、简单拼图 | 让目标细节看得见，保留理解它需要的上下文 |
| 顺手转一个好笑的东西 | 已确认来源的反应图、动物图、短字图 | 按原图使用条件保留归属；有现实专名时先判断人物是否认识，或改写成他会用的表达 |
| 沿用自己的旧图 | 原有低分辨率图、带压缩痕迹的图、已经用过的裁切版本 | 保留材料本来的样子；字和关键动作仍可辨认，裁切与处理沿用来源允许的范围 |
| 展示认真做的东西 | 清楚的照片、完整截图、自制图或生成画面 | 完成程度配合人物当时花的时间和目的，作品细节与正文相符 |

画面质量随来源和用途变化。手机取景偏斜、局部遮挡、普通字体、随手圈画和原有糊图都可以成立；拍得清楚、认真排过版也有对应的使用场景。选现成图时保留其合适的样貌，自制时从这个人手边的工具与当下精力出发。

## 从现实用法学表达

观察一个梗时，依次看“在回应什么”“借了什么形式”“这次带着什么态度”。这一拆法参考 Limor Shifman 的[论文摘要](https://cris.huji.ac.il/en/publications/memes-in-a-digital-world-reconciling-with-a-conceptual-troublemak/)中的内容、形式与立场；既有阅读范围为摘要和书目信息。

## 参考案例

以下是2026-11-09留存的文字观察，适合参照表达动作：

### ME01｜做饭失败后的吐槽与接话

- **来源与范围**：[豆瓣：做饭失败后的吐槽与接话](https://www.douban.com/group/topic/504108531/?_spm_id=MTUxNjQ1MDMz)。已读正文、第一页最赞回复及楼主引用的回复；附图留待查看。页面显示编辑于2026-10-30，原始发布时间未知。
- **参考要点**：先认真夸，括号里突然把试吃推给别人；沿面量变化写递进；给失败的菜换个名字。改编时保留这类动作，再换成当事人的具体处境。

### ME02｜认出模板与听完仍不理解

- **来源与范围**：[Reddit：这些奇怪的 meme 是什么](https://www.reddit.com/r/OutOfTheLoop/comments/yefe3l/whats_the_deal_with_these_unusual_memes/)。已读主帖及 Best 下返回的部分评论，含 Loss 解释与 The Game 分支；画面和隐藏回复留待查看，原始日期未知。
- **参考要点**：有人认出模板就笑，有人听完解释仍觉得一般，有人只接自己认识的部分。人物可以把反应停在各自理解的地方。

同一张图可以是自嘲、夸奖、敷衍或故意装正经。看原帖如何触发它，再看它改变了哪一句话的意思；改编时把这个作用带进人物的处境。独自发一张、重复旧图、得到回应、无人接梗，都可以成为一次完整的发言。本篇继续保存可回查的资源与使用观察。
