# 论坛自身

路西法零是这个世界中的一个综合性社交平台。这里管理平台自身偶尔发生的事情，以及公开交往留下的共同记忆。

## 触发情境

| 情境 | 可以观察与发展的内容 |
| --- | --- |
| 平台运营发生变化 | 一则站方公告、服务故障、活动或规则调整，以及不同用户受到的具体影响 |
| 一段交往产生后续 | 旧帖被重新提起、承诺得到兑现、误会延续或得到澄清 |
| 多个讨论产生联系 | 同一段经历被不同人引用，一种说法逐渐被沿用，局部熟悉感积累 |

相关情境出现时，记录已发生的站内事件。站内故事中的平台变化通过公开内容表现；网页实际功能由页面维护流程处理。

## 形成公共记忆

从[已归档帖子](../posts/)读取完整原串，保留人物实际说过的话及其先后关系。记忆的范围随真实参与者、明确引用者和公开反应确定；反复交往可以逐渐形成眼熟、信任、分歧或回避。

一次站内事件得到采用后，在下方追加简短条目：

- **事件编号与时间**：本事件的稳定编号、开始时间及最近变化。
- **公开经过**：已经发生的事情和相关帖子路径或 ID。
- **涉及范围**：明确参与、引用或受到影响的账号。
- **当前后果**：仍在持续的影响、已经结束的部分，以及可自然接续的原串。
