# 负面、八卦与冲突研究

这里研究不满、猜疑、护短和争胜欲怎样成为发言，以及一个话头怎样从抱怨变成争执。以下是定向挑选的讨论样本，用来理解交流机制；各站内容比例另需连续采样统计。抽取与数量安排见[抽签规则](../docs/lottery.md)，正文组织见[写作与改编](../docs/writing.md)，回复形成见[评论与点赞](research-comments.md)。

## 什么算负面

正文与实际配图表达了可指出的负面态度或矛盾：具体不满、嘲讽、指责、猜疑、敌意、失望、委屈、嫉妒，或围绕利益与责任的冲突。审读时指出当事人在气什么、怀疑什么、贬低谁，或怎样与别人发生分歧。语气可以很淡，笑脸和玩笑也可能带着攻击。

普通问句、坏掉的物件和一次失败提供情境；是否计入负面，看这条发言实际表达的态度。中性询问修法、单纯报一个数字、只转述消息，按它们各自的作用保留。八卦中的负面来自可争的说法、声誉落差、怀疑或利益纠葛；信息缺口给追问、猜测和质疑留下空间。

## 从哪里找有张力的材料

| 材料里的矛盾 | 取材时具体看什么 |
| --- | --- |
| 吃亏与占便宜 | 谁付出了时间、钱或面子，谁认为这是对方自愿；同一个人怎样给自己和别人用不同标准 |
| 护短与踩一脚 | 喜欢的作品、圈子或熟人被批评后，参与者先维护哪一点；批评者又抓住哪处破绽 |
| 八卦与爆料 | 亲眼所见、转述和猜测分别到哪一步；什么时间、原话、利益关系或前后矛盾值得追问 |
| 资格与解释权 | 谁在拿资历、经验、付出或受害经历压人；谁认为自己被扣帽子或被管教 |
| 未被接住的情绪 | 作者要认同，回复给方案；作者要答案，回复拿他的处境开玩笑；作者补条件后，别人嫌他事多 |
| 退让与不甘心 | 当事人暂时认输、删一句或离开时，旁人怎样继续翻旧话；表面收场后，实际损失或不满还剩什么 |

一份材料记录：**具体冲突点、各方想要什么、各自知道什么、哪句话触发下一轮，以及回答出现后争点是否改变**。同一个矛盾可以有诚恳辩解、理直气壮的双标、短促反问和带笑的冷话，顺着实际来回判断，单句尖刻不足以说明整场争执。

## 异议怎样转成抬杠

先分清原来的分歧。有人不认可事实依据，有人不接受处置办法，也有人只是厌烦说话方式。反对、追问证据和纠正用词本身都能推进理解；当事人骂对方“杠精”，也只说明他怎样评价对方。核对后续是否承接了回答：补上信息后能缩小问题、改口或承认一处，和反复略过已经给出的答案，是不同的过程。N10里反对封禁的解释有一支得到楼主认同，不能因为站在楼主对面就写成故意找茬。

争胜可以从原话的一小处获得入口。N09把工作流的不满接成行文资格之争；N08从求陪伴转到词义，再转到谁能用一句话证明自己没有抬杠。此时观察参与者如何把自己的要求变成下一轮门槛：要求解释一个词，解释后又换一个词；拿到核对材料后转问对方的动机；用对方的生气或继续解释证明对方有问题。每次转向要有眼前触发它的话，保留双方真正相争的部分，不把所有不同意都套成偷换概念。

旁人的加入也会改变代价。有人来核对，有人沿一句讥讽起哄，有人维护被指责的一方，原先愿意解释的人也可能开始争谁先冒犯、谁配结束谈话。N04里身份指认让话题转向跨站指认的资格；N09里“别回复”又被下一位当作占最后一句。发言者未必从头就是一个固定的“杠精”角色，当前受挫、被围观或急于保住面子都可能改变这次的做法。

这些是定向样本中局部发生的偏差，不是每串的必经步骤，也不据此推算出现比例。尖话可以无人接，澄清可以收住一支，其他人仍可讨论原来的事；N08的长争执旁边一直有人讲自己的生活，N10的事实核对收住一处后，动机争议仍未解决。取材时同时保留这些未升级、分叉和中断；逐条回应与整串节奏沿[评论与点赞](research-comments.md#组织一串交流)，人物怎样表达沿[说话方式研究](../users/research-speech.md)。
