# 素材-精选参考

用户挑选后长期保留的案例。每个案例独立成文，严格分为「实际案例」和「对案例的分析」两部分；本页只作索引，不作为样本。自动采集只刷新[每日舆论](../sources-daily-opinions.md)的当日区，不得改写本目录及其中任何文件。

| 001 | [从「口味不搭」到「说一下都不行」](001-matcha-dessert-comments.md) | 非正面评价与个人偏好报告的争论潜势，回应升级、元争论、围观及异步参与 |

新增案例直接放在本目录下，使用独立的 `.md` 文件，并更新上表。实际案例尽量保留原话、错字、标点、表情、回复关系、可见时间及赞数；网名轻度且一致地脱敏，不补写截图未显示的信息。分析区分观察事实与解释，不把假设对话混入转录。

取材边界沿用 `<!-- samples:start -->` 与 `<!-- samples:end -->`：每篇仅一对，包住实际案例中的完整脱敏场景、转录约定与交流记录。来源平台说明、原图文件名和第二部分分析放在标记外。标记内及案例标题继续检查平台名、原账号、链接和联系方式；标记不是跳过脱敏的许可。非空案例缺少边界时会报错，避免将研究正文误作素材。

读取时按文件名顺序发现本目录直属 Markdown 文件；`README.md` 不产生样本。每个案例的标记内内容整体生成一个样本，三级标题不拆分，分析不进入写作素材。完整文档（包括索引、来源说明和分析）仍进入准备阅读包和变更检查；增删案例或修改分析后需要重新准备。每日素材仍按原有规则分段，规定数量的新鲜案例仍只从本轮每日采集中取得，不能用精选补数。
