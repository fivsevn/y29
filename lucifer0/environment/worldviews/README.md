这里保存人物共同生活的世界或地区，以及各自发生的公共事件。

## 文件组织

每个世界使用独立目录，目录名作为稳定编号；同名 Markdown 保存设定，`events.md` 保存动态事件。例如：

```text
worldviewA/
  worldviewA.md
  events.md
worldview0/
  worldview0.md
  events.md
```

人物基本情况表的“所属世界观”填写对应编号；未指定时使用 `worldview0`。阅读人物时，同时读取所属世界的设定和动态。人物自己的经历、财务、亲属与具体关系继续写在本人档案。

## 设定内容

从[TEMPLATE.md](TEMPLATE.md)建立世界设定，按自然条件、历史、人、资源、制度和日常生活组织内容。重要的生活条件可以多写，资料较薄的部分保持简短；世界观0保留现实改编的简要说明。

同一事实放在最合适的一栏，相关影响接在相应位置。例如，能源的取得与消耗归资源，谁取得收益归分配，谁能改变规则归治理，个人怎样因此生活归日常。历史写已经形成的格局，风险写持续的薄弱环节。

## 动态更新

采用的公共变化写入所属世界的 `events.md`。阅读现实报道或原话题后，按这个世界的条件重组机构、人物和经过，记录现实依据、已发生的事实、时间、适用范围、当前阶段、持续影响及最近更新日期。每项使用稳定编号，后续沿原项补充进展；有关帖号按实际发表情况填写，可以留空。

事件可以经历预告、实施、扩散、调整和余波。人物接触到它时，可以当时或之后发言，也可以让它继续作为背景。已有变化留下的价格、安排、认知与争议，沿后续进展接续。待采用的候选材料保留在本次观察记录中。
