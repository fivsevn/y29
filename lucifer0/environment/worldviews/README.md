# 世界与地区

这里保存人物共同生活的世界或地区：自然条件、历史形成、资源与制度，以及普通人能接触的生活环境。每个世界按同一套栏目组织，适用于现实地区、历史社会和不同类型的虚构世界。

## 使用与补充

从 [TEMPLATE.md](TEMPLATE.md)建立一份世界或地区文档，文件名作为稳定编号。人物基本情况表的“所属世界观”填写这个编号；阅读人物时一并理解对应的公共条件。人物的经历、财务、亲属与具体关系继续写在本人档案。

栏目由本项目按生活所需自主整合：先界定时空与自然条件，再说明人、资源和社会怎样运转，最后落到日常、风险与当前变化。各栏围绕具体的获得方式、限制、代价和差异写成连贯设定；重要的生活条件可以多写，资料较薄的部分保持简短。现实地区注明适用地域和日期，不同地区分别保留条件。

同一事实放在最合适的一栏，相关影响接在相应位置。例如，能源的取得与消耗归资源，谁取得收益归分配，谁能改变规则归治理，个人怎样因此生活归日常。历史写已经发生的形成过程，风险写持续的薄弱环节，当前状态写眼下正在运转和变化的事。

世界文件保存共同设定与长期条件。[世界趋势](../world-trends.md)接续采用后的公共事件、阶段和余波；[日常生活](../everyday-life.md)提供现实取材；[论坛自身](../forum.md)保存站内共同经历。更新沿已经发生的变化回写相应位置。
