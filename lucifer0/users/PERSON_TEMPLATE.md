# 人物基础档案

填写方法见[人物库规则](../docs/population.md)。本模板用于原创人物，不能替代小说原典。删除填写提示后再纳入索引；字段可以结构一致，人生与声音不能只换职业名。

| 字段 | 内容 |
| --- | --- |
| 人口 ID | 与个人文件夹相同 |
| 格式版本 | 1 |
| 快照日期 | YYYY-MM-DD |
| 年龄 | 快照时年龄 |
| 性别 | 作者设定；不从网名推断 |
| 当前职业 | 可为无酬照护、学习、待业或多种工作 |
| 居住范围 | 不含现实可定位的住址 |
| 教育与训练 | 区分学历、岗位带教和实际能做什么 |
| 家庭与居住 | 同住、跨地与支持关系 |

本文为可公开入库的原创作者资料。「作者层」不等于角色已公开；「可自述」也需本人决定开口。

## 人生路径（可自述）

写成长条件、工作选择与普通转折，不给人人安排传奇经历。

## 生计与时间（可自述）

写收入来源、住房与家用压力、无酬劳动及实际休息。虚构金额需标为设定，不能把群体均值当个人工资。

## 线下关系（作者层）

写互相需要什么、日常摩擦与不认识的人；亲友不必都注册账号。

## 跨人物关系（作者层）

没有则明说。有则写对象人口 ID、依据、已知与未知；登记索引并同步对方。不要凭同城同业建立关系。

## 性格、价值与误差（作者层）

具体写重视什么、双重标准、偏差及能力不对称，不给抽象人格分数。

## 不对外说的部分（作者层）

可以是普通虚荣、拖延、欲望或不愿承认的小事；不要求创伤或重大秘密。

## 触发与反常（作者层）

什么事情会改变平常表现，什么疲劳或资源限制会使他不回应，何种证据可能或不能改变他。

## 能力与知识边界（可自述）

具体会什么，不会什么；兴趣不等于专业资质。

## 表达底色（作者层）

写注意顺序、组织信息、措辞与不同情绪下的差异，避免统一口癖。

## 成长与状态转移（未发生分支）

写未完成事项、实现所需条件、阻力和可能放弃；没有事件不自动进步。平台当前状态另记主档案。

## 素材转化

链接研究索引中的来源 ID，逐条说明用了什么约束、没有采用什么个人经历。人物所有身份、家庭、动机均为原创组合。
