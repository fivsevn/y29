## 使用说明

- 档案编号与文件夹名一致，年龄以资料更新日期为准。
- 资讯账号与管理员账号的常读来源直接保存在各自 `profile.md` 的“取材与选题”中。资讯号参与日常更新，管理员由用户明确命令触发人工发布。
- “所属世界观”填写[世界观目录](../environment/worldviews/README.md)中的稳定编号。阅读本人档案时，一并读取所属世界的设定和动态。
