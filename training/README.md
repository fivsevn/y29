# 飙肌野郎 / STEEL MUSCLE RUN

七日训练叙事游戏，从 57training 体验卡开始，经历训练、朋友碰头、晚饭和一周结束后的手机消息。

- 从仓库根目录运行 `npm start`，打开 `http://127.0.0.1:4173/training/`。
- 修改内容、规则或演出前，先看 [内容与规则维护指南](EDITING.md)。
- 页面入口为 `index.html`；规则、状态和界面目前共同放在 `game.js`，内容分布在四个数据文件中。
- 本次体验只存在于内存，刷新或关闭页面后清除；没有续玩存档。
- 支持单人，或最多三位好友同行；固定好友有各自的出勤，邓子只参加饭局。

从仓库根目录执行：

```bash
node --test tests/training*.test.js
npm test
npm run build
```

单元测试验证规则与模拟控制器；发布前还需要在浏览器检查选项确认、逐字显示、滚轮、像素画面和整周手机收尾。
